What is HTTP?

Hypertext Transfer Protocol (HTTP) is a stateless protocol for distributed hypertext information systems. It is used across the internet to enable the transmission of hyper media documents such as HTML(for webpages), CSS, JavaScript, Images and video. This describes at a high-level the history, architecture, growing pains, and the future of HTTP.

Key Terms

  • HTTP: Hypertext Transfer Protocol
  • Client-Server: Request and response architecture
  • Stateless: No session memory retained between requests
  • TCP / QUIC: Underlying transport protocols
  • TLS: Cryptographic security layer (HTTPS)
