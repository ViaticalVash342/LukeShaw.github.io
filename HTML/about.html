About This Project

This website was created for the IT 3203 course (Project Milestones #1 & #2). The goal of this project is to build an interactive educational website using HTML, CSS, and JavaScript to present research on the history, architecture, and evolution of the HTTP protocol, complete with a dynamic self-assessment quiz.

Web Development Technologies Used:

  • HTML5 document structuring and semantic form controls
  • CSS Grid and Flexbox layouts
  • External stylesheet management and dynamic state styling
  • JavaScript DOM manipulation, event handling, and countdown timers
  • Version control and deployment via GitHub Pages
