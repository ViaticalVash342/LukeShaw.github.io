The Birth of the World Wide Web

The foundation for HTTP was laid down by British Scientist Tim Berners-Lee in 1989 while he was working at CERN. He created three core technologies. HTML for structure, URLs for resources, and HTTP as the protocol that would be used to request and transfer the media over the internet.

Evolution of the Protocol

  • HTTP/0.9: The first iteration of HTTP, retroactively named HTTP/0.9, was put into use in 1991. It was very basic and was made up of a text only design used only for retrieving static documents.
  • HTTP/1.0: In 1996 the Internet Engineering Task Force (IETF) published RFC 1945, formalizing HTTP/1.0. HTTP became multimedia with the introduction of Content-Type allowing the protocol to support file types beyond text.
  • HTTP/1.1: In 1997 the IETF released HTTP 1.1 introducing optimizations.
  • HTTP/2: In order to solve the problems with HTTP/1.1 without changing any of the core concepts already well established, HTTP/2 was developed by the IETF in 2015.
  • HTTP/3: To solve the limitations of TCP, the IETF developed HTTP/3 in 2022.
